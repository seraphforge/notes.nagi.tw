# notes.nagi.tw

Personal research notes, engineering notes, project records, competition and CTF records, technical exploration, and personal writing.

## Content

- `articles/research/` — research, experiments, observations, and interdisciplinary exploration
- `articles/projects/` — records of things built and project development
- `articles/engineering/` — engineering implementation and systems exploration
- `articles/security/` — work whose primary subject is information security
- `articles/ctf/` — CTF writeups, challenges, and competition records
- `articles/personal/` — personal stories, reflections, and learning journeys
- `assets/images/` — local images referenced by articles

Language variants stay in the same category. Chinese uses `name.md`, English uses `name.en.md`, and Japanese uses `name.ja.md`.

See [migration-report.md](migration-report.md) for provenance, metadata changes, and validation notes.
