# 好久沒更新了，來記一下最近到底在幹嘛

幹，我好像真的很久沒更新這裡了。

原本一直想說等哪個專案做完、比賽打完，或有什麼比較完整的東西再來寫。

結果就是事情一件接一件，最後什麼都沒寫 XD

最近剛好開始整理自己的東西，才發現這幾個月碰的東西有夠雜。

資安、網站、AI、醫療、樹莓派、Homelab，最近又開始碰 Edge AI。

所以乾脆先寫一篇近況，不然再拖下去大概又要消失半年。

## 最近還有在搞資安嗎？

有。

只是現在已經不像以前幾乎全部時間都在 CTF 上了。

CTF 我還是會打，Web、Linux、Malware 這些也還是我很有興趣的東西，只是最近開始把時間分給其他東西。

其中一個差最多的應該是，我開始寫比較多完整的系統。

以前看到一個網站，腦袋第一個想法可能是：

「這邊能不能打？」

現在有時候反而會變成：

「幹，如果這個東西是我要做，我後端要怎麼寫？」

然後真的自己寫之後，就會發現以前覺得「這開發者到底在寫三小」的東西，有些真的不是開發者智障。

有時候單純就是需求很白癡。

## 醫療資安還在繼續

這個算是我目前滿想繼續做下去的方向。

我之前就在碰醫療資訊跟資安，最近又因為比賽的關係，開始想把 AI Agent、Edge AI 這些東西塞進去。

但我現在比較不想做那種：

「我們使用 AI 分析資料，提升效率 87%。」

這種看完不知道到底解決什麼問題的東西。

我現在比較在意的是實際場景。

例如醫院斷網怎麼辦？

設備不能把資料送出去怎麼辦？

敏感資料是不是一定要上 Cloud？

AI 如果可以操作系統，那它到底可以拿到多少權限？

所以最近一直在研究離線 AI 跟 Edge Computing。

然後就掉進另一個坑。

模型多大？

記憶體夠不夠？

推論速度多少？

量化之後差多少？

Jetson 跑不跑得動？

原本只是想做一個醫療資安專案，最後莫名其妙開始研究硬體。

合理。

## 然後我又開始搞 Homelab

最近家裡那台 Ubuntu 也被我抓來當 Homelab 了。

沒有顯卡。

所以一開始我還在想：

「沒有 GPU 的 Server 到底可以幹嘛？」

結果後來發現根本一堆東西可以架。

Docker、API、資料庫、監控、VPN、DNS、Log Server、Git、測試環境……

甚至可以直接拿來當我之後專案的內網環境。

目前還在慢慢整理。

而且自己真的架一台長期開著的 Linux 主機，跟平常開 VM 差很多。

SSH 登不進去、網路設定炸掉、服務不知道為什麼沒起來、權限有問題。

然後研究半天。

最後發現：

密碼打錯。

:)

## 樹莓派也被我挖出來了

這東西也是另一個坑。

最近把 Kali 裝到 Raspberry Pi 上面，開始搞 SSH、RDP、Wi-Fi Adapter，還有那塊 3.5 吋 LCD。

一開始螢幕沒畫面。

處理完之後有畫面了。

然後觸控有問題。

處理完觸控之後方向又不對。

Linux 

不過這次重新搞 Raspberry Pi，我反而學到不少以前沒真的理解的東西。

以前很多 Linux 指令就是：

「網路上說要打這個，那我就打。」

現在至少會開始去看 systemd、network interface、driver、framebuffer 到底發生什麼事情。

還是會壞。

但至少現在知道自己是怎麼把它搞壞的。

## 最近最多的大概還是比賽

今年真的打太多東西了。

CTF、Hackathon、AI、研究計畫……

而且我最近最大的感覺是：

會做東西跟會做「比賽專案」其實是兩回事。

以前很容易看到一個新技術就：

「幹這個好酷，我要塞進去。」

現在開始會先問：

「所以塞這個到底要幹嘛？」

尤其最近在準備一些 AI 跟醫療相關的東西之後，這個感覺超明顯。

你可以塞 LLM、Agent、RAG、Edge AI、Blockchain，全部塞爆。

然後評審問一句：

「所以你解決了什麼？」

沒了。

直接下去。

所以我現在做專案會先逼自己把問題講清楚，再決定要用什麼技術。

至少努力這樣做啦。

有時候看到新東西還是會忍不住亂塞。

## 大概就這樣

最近其實還有很多東西沒寫。

有些專案還在做，有些比賽還沒打完，有些東西目前也只是很白癡的 Prototype。

所以之後應該會慢慢把它們整理上來。

大概會分成：

資安、開發、比賽、心得。

CTF Writeup 會繼續寫。

Homelab 跟 Raspberry Pi 的踩坑也想記一下。

醫療資安跟 Edge AI 如果最後真的做出一個能看的東西，也會把整個過程整理出來。

至於最後到底會走資安、Cloud、AI，還是跑去做其他東西……

不知道。

先做再說。

反正這個 Blog 本來就是拿來記錄我到底都在搞什麼東西的。

那就繼續記吧。
